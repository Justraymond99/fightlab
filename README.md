# FightLab

Controller-first fighting game practice software inspired by Aimlabs and Kovaak's.

## First milestone

Detect a connected controller, show its name, and render a live normalized input history.

## MVP direction

- Street Fighter 6
- Terry as the first supported character
- Controller detection and live input history
- Fighting-game notation normalization
- Combo validation and practice drills

## Run locally

```bash
npm install
npm run dev
```

Connect a controller, press any button once so the browser exposes it, and FightLab will begin reading inputs.

> If it doesn't make me a better fighting game player, don't build it.
